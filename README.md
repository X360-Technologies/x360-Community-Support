
# x360 AI – Intelligent Automation Framework

## 📌 Introduction

**x360 AI** is an intelligent test automation platform designed to streamline and scale your QA processes across:

- 🌐 Web
- 🧪 API
- 📱 Mobile
- 🗃️ Database
- 🚀 Performance

It offers a modern, intuitive UI with real-time insights into test coverage, regression, and execution results.

### 🔍 Key Features

- **AI-Generated Tests**: Automatically create test cases based on system behavior or user requirements.
- **Cross-Domain Coverage**: Unified support for multiple platforms.
- **Comprehensive Dashboards**: Real-time stats on total cases, execution status, and trends.
- **Smart Insights**: Detect failures, regressions, and anomalies instantly.
- **User-Centric Design**: Intuitive navigation and test intelligence visuals.

## 🧪 Test Case Hub

Organize and manage test cases manually or via AI generation.

### Steps:

1. **Navigate to Hub**:
   - Sidebar → Select module (Web/API/etc.) → Click **Test Case Hub**
2. **Folder Structure**:
   - Add new folders
   - Filter within folders
   - Maintain hierarchy

### Test Case Fields:

| Field         | Description                            |
|---------------|----------------------------------------|
| ID            | Auto-generated (e.g., TC-0255)         |
| Title         | Short description                      |
| Priority      | Severity (e.g., High)                  |
| Testcase Type | Tags (e.g., Smoke, Regression)         |

### Actions:

- ✅ Select multiple cases
- ➕ Create new test case
- ▶️ Trigger test run

## 🤖 Manual vs AI-Generated Test Cases

| Type              | Description                                                                 |
|-------------------|-----------------------------------------------------------------------------|
| Manual            | Created by QA team with expected outcomes                                   |
| AI-Generated      | Created automatically based on input or history; editable and reviewable    |

---

## ⚙️ How AI Generates Test Cases

### Step-by-Step:

1. **Input Scenario**: Provide your scenario to **Ask x360 AI bot**
2. **Clarifications**: AI may ask follow-up questions to ensure accuracy.
3. **Generation**: AI generates both positive and negative test cases.
4. **Command**: Use `/createtestcases` in chat to save and organize test cases.
5. **Review**:
   - Check title, description, priority, steps
   - Edit/delete as needed

## 🧪 Test Run

### Creating a Test Run:

1. **Select Cases**: Go to Test Case Hub and choose test cases.
2. **Click**: Create test run.
3. **Name It**: Provide a meaningful name.
4. **Run**: Execution begins for selected test cases.

### Evidence Generated:

- 📄 Execution Logs
- 🎥 Video Recordings
